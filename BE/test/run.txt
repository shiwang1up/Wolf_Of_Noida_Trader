# 🐺 Wolf of Noida — Backtesting Guide

## 1. Fetching Real Data (Binance)
The `fetch-binance.js` script auto-paginates the Binance API to fetch historical data perfectly aligned for the backend.

```bash
# Fetch 1 year of BTC daily candles
node scripts/fetch-binance.js BTCUSDT 1d 2023-01-01 2024-01-01

# Fetch 6 months of BTC 4-hour candles
node scripts/fetch-binance.js BTCUSDT 4h 2023-07-01 2024-01-01
```
*(Supports: 1m, 3m, 5m, 15m, 30m, 1h, 2h, 4h, 6h, 8h, 12h, 1d, 3d, 1w, 1M)*

---

## 2. Running AI Backtests
Commands have been heavily simplified. `step_mins`, `lookahead_mins`, and precise timestamp formatting (`T00:00:00Z`) are now **auto-calculated** behind the scenes.

#### A. Backtesting the Real Crypto Data (Binance)
Use the `--table=binanceCandle` flag to specifically target the real crypto data you fetched using the script above:
```bash
node scripts/backtest.js BTCUSDT 1d 2023-01-01 2024-12-31 --ai --table=binanceCandle
```

#### B. Backtesting the Legacy Test Data (12h SPX Data)
If you omit the table flag, it defaults to the 12h test dataset:
```bash
node scripts/backtest.js BTCUSDT 12h 2020-01-01 2021-02-03 --ai
```

---

## 3. Database Management (Clean Slate)
Sometimes you want to wipe the `BinanceCandle` database before pulling fresh data:

```bash
# 1. Nuke ALL Binance data globally (total reset)
node scripts/fetch-binance.js BTCUSDT 1d --clear-all --clear-only

# 2. Wipe just one specific pair + timeframe (e.g. only clear BTCUSDT 1d)
node scripts/fetch-binance.js BTCUSDT 1d --clear --clear-only

# 3. Clear existing BTC 1d data and immediately start fetching fresh data
node scripts/fetch-binance.js BTCUSDT 1d 2024-01-01 2024-12-31 --clear
```

Here are the commands you need for everything:

1. Run with Different Engines (Full 7-Year Backtest)
The 

run_yearly_backtests.js
 script runs all years (2019–2026) sequentially. By default, it uses the Moderate engine (formerly index.js), but you can pass flags to switch:

Moderate (Default): node scripts/run_yearly_backtests.js (or add --balanced)
Passive Engine: node scripts/run_yearly_backtests.js --passive
Aggressive Engine: node scripts/run_yearly_backtests.js --aggressive
2. Fetch Data from Binance (>1000 records)
The 

fetch-binance.js
 script automatically paginates for you! Binance limits each request to 1000 bars, but this script will recursively keep fetching 1000-candle batches until it covers your entire requested date range.

Fetch a massive multi-year range:
bash
node scripts/fetch-binance.js BTCUSDT 1d 2018-01-01 2026-01-01
Fetch data for a shorter timeframe (e.g., 1h) which requires many batches:
bash
node scripts/fetch-binance.js BTCUSDT 1h 2024-01-01 2025-01-01
(Optional flag: add --clear-all at the end to wipe the Binance table before fetching fresh data)

3. Run a Specific Year or Custom Date Range
To run a single, specific date range, you bypass the yearly runner and run the core 

backtest.js
 script directly. Note that we must specify --table=binanceCandle so it uses the data we fetched.

Example (Run 2021-2022 using the Passive engine):
bash
node scripts/backtest.js BTCUSDT 1d 2021-01-01 2022-01-01 --table=binanceCandle --fees --passive
4. Run a Specific Year WITH the Visualizer UI
To boot up the web UI so you can see exactly where the engine bought/sold on the chart, just append the --ui flag to the direct 

backtest.js
 command:

Example (Run 2024-2025 with UI & Moderate engine):
bash
node scripts/backtest.js BTCUSDT 1d 2024-01-01 2025-01-01 --table=binanceCandle --fees --ui
Once it says it's waiting for a UI connection, open a browser and go to http://localhost:3000 to watch the backtest play out!
